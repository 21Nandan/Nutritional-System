# Security policy

Please report vulnerabilities privately through GitHub's **"Report a vulnerability"** button
(Security tab → Advisories) rather than in a public issue. You'll get a reply within 7 days.

In scope: the API (`backend/`, `api/`), the frontend (`frontend/`) and the deployment configuration
(`vercel.json`). The server stores no personal data: profiles, history and saved items live in the
visitor's browser. Contributed products are public and unreviewed.

Supported version: the `main` branch as deployed at https://eatgood26.vercel.app.
